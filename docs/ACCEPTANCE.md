## 黑蓝紫视觉升级验证

本轮将全站调整为黑色背景、蓝紫色强调色和深色面板，覆盖首页、导航、移动菜单、表单控件、状态标签、Markdown 与代码高亮。首页新增双语介绍、题目锚点入口、轨道装饰和 Canvas 粒子连线。未修改数据库迁移或业务规则，本轮未重复数据库验收。

- 代码审查确认粒子不拦截点击，并以 `aria-hidden` 排除装饰内容；窄屏最多 28 个、桌面最多 74 个粒子，Canvas 像素比限制为 2。
- 代码审查确认首页离开视口或页面进入后台时取消动画帧；系统启用 `prefers-reduced-motion` 时只绘制静态粒子；卸载时取消帧请求，断开观察器并移除事件监听器。减少动效时还关闭平滑滚动与主要按钮位移。这些生命周期分支经静态检查，未进行运行时帧率、后台耗电或系统动效偏好的专项测量。
- 对深色页面的文字、控件、状态与代码样式进行了静态检查；输入框和文本域的占位文字已提高亮度，修复此前半透明文字对比不足的问题。业务数据、表单提交、权限与投票调用路径保留；本轮没有真实数据的交互回归覆盖。
- 内置浏览器实测 1280 × 720 桌面视口下的中文/英文首页，以及 390 × 844 手机视口下的中文/英文首页、菜单展开与折叠、语言切换。
- 实测首页主按钮跳转到 `/#problems` 并滚动至题目区域；手机页面宽度等于 390 像素视口，没有页面横向溢出。
- 实测首页存在一个粒子 Canvas，导航到 `/login` 后不再存在；浏览器未报告 console error。未配置 Supabase 时，登录页配置提示保持深色主题。
- 本轮 `npm test` 7/7 通过。最后的占位文字与首页排版微调仅涉及样式；微调后的 `npm run typecheck`、`npm run lint` 与 `npm run build` 均通过。浏览器已刷新最终 production 构建并再次确认中文首页布局，保留首页预览；未因纯样式微调重复安全测试或数据库验收。
