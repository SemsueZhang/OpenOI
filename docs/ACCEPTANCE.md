# MVP 验收记录

## 已完成的验证

- 依赖安装 `npm ci` 已通过；升级到 Next.js 16.3.6、React 19.3.0 后，已在 Node.js 22.23.3 下重新运行 `npm run typecheck`、`npm run lint`（零警告）、`npm run build` 与测试，均通过。
- `npm test` 7/7 通过，覆盖原始 HTML、危险 URL、KaTeX、GFM、公式、代码高亮、代码围栏、重定向及用户名/标签校验。
- `npm run test:db:docker` 已通过：在隔离 Docker PostgreSQL 15 中实际执行最终完整迁移与 `tests/database/acceptance.sql`，包含空投票目标类型拒绝，以及 anon/authenticated 对三个查询视图均无写权限的断言。已验证注册资料触发器、伪造作者/直接修改状态拒绝、匿名写拒绝、越权编辑、孤立目标拒绝、自投拒绝、转票/撤票、状态优先级及级联删除。
- 实际执行 `scripts/test-db.sh` 的双连接并发场景：同一 Hack 相反投票形成平票；同一 solution 下不同 Hack 并发投票；删除 Hack 与投票竞争。已验证最终票数、状态和级联一致性，测试容器已清理。
- 上述 PostgreSQL 使用 `plain_postgres_bootstrap.sql` 模拟 Auth 表、角色与 `auth.uid()`，验证数据库行为，不等于运行 Supabase Auth/PostgREST 服务。
- 代码审查已检查：列级授权保护作者/目标/状态，security-definer RPC 验证身份与所有权，父 solution 先加锁，状态聚合触发器，安全站内跳转，SSR cookie 会话刷新。登录/注册入口保留当前路径和查询参数作为站内返回目标。
- 注册成功和邮箱确认失效时提供双语重发入口，调用 `resendConfirmation` / `auth.resend`，复用安全确认回调并返回中性反馈；真实邮件送达和确认仍需端到端验收。
- 已通过内置浏览器实测未配置 Supabase 的页面、中文/英文切换、刷新后语言 cookie 保持；已在 390 × 844 手机视口检查布局、菜单展开与手机端语言切换。最终预览中也检查了带 `problem_id` 查询参数页面的页头登录/注册链接，确认完整编码并保留返回目标。

最终迁移已完整实测，浏览器验证覆盖上述无配置场景；尚未在真实 Supabase 数据、账号与邮件服务上完成端到端验证。

## 黑蓝紫视觉升级验证

本轮将全站调整为黑色背景、蓝紫色强调色和深色面板，覆盖首页、导航、移动菜单、表单控件、状态标签、Markdown 与代码高亮。首页新增双语介绍、题目锚点入口、轨道装饰和 Canvas 粒子连线。未修改数据库迁移或业务规则，本轮未重复数据库验收。

- 代码审查确认粒子不拦截点击，并以 `aria-hidden` 排除装饰内容；窄屏最多 28 个、桌面最多 74 个粒子，Canvas 像素比限制为 2。
- 代码审查确认首页离开视口或页面进入后台时取消动画帧；系统启用 `prefers-reduced-motion` 时只绘制静态粒子；卸载时取消帧请求，断开观察器并移除事件监听器。减少动效时还关闭平滑滚动与主要按钮位移。这些生命周期分支经静态检查，未进行运行时帧率、后台耗电或系统动效偏好的专项测量。
- 对深色页面的文字、控件、状态与代码样式进行了静态检查；输入框和文本域的占位文字已提高亮度，修复此前半透明文字对比不足的问题。业务数据、表单提交、权限与投票调用路径保留；本轮没有真实数据的交互回归覆盖。
- 内置浏览器实测 1280 × 720 桌面视口下的中文/英文首页，以及 390 × 844 手机视口下的中文/英文首页、菜单展开与折叠、语言切换。
- 实测首页主按钮跳转到 `/#problems` 并滚动至题目区域；手机页面宽度等于 390 像素视口，没有页面横向溢出。
- 实测首页存在一个粒子 Canvas，导航到 `/login` 后不再存在；浏览器未报告 console error。未配置 Supabase 时，登录页配置提示保持深色主题。
- 本轮 `npm test` 7/7 通过。最后的占位文字与首页排版微调仅涉及样式；微调后的 `npm run typecheck`、`npm run lint` 与 `npm run build` 均通过。浏览器已刷新最终 production 构建并再次确认中文首页布局，保留首页预览；未因纯样式微调重复安全测试或数据库验收。

以上浏览器验证在未配置 Supabase 的状态下完成，不能代替真实题目详情、登录、发布、评论、投票及邮件确认的端到端验收。
